Admin · Flowchart

Admin console

One role-guarded account branches into five areas: dashboard, catalog, staff, settings, and reports. Everything reads the one RTDB stream.

Spec

Sign in
Admin account at /admin, role-guarded.
Dashboard
KPIs, monthly GCash/cash mix, 7-day trend, best-sellers, peak hours, refunds-owed badge.
Products + inventory
Add/edit product + image (server resize → base64 in RTDB); categories + per-product add-ons; one-click promo (% or ₱ → computed label); hide toggle = 86 (no food stock); inventory = rental units with −/+ steppers and Add stock (supplier · qty · date), low-stock flags, restock button; rental items CRUD (name · image · price/day · units).
Staff accounts
Create / demote / delete (name + Google email · Google-only, no passwords). Each evicts the cached role. No public signup.
Settings
Hours per weekday + force-close + scheduled date-range closures → public open/closed badge; announcement banner; GCash number + QR upload (both required before ordering opens); rotate kitchen secret; reservation capacities (smart default); Complete setup banner until the payment block exists.
Reports
Sales · payments (GCash vs cash) · reservations · rental bookings with date filters; refunds owed → Mark refunded; Activity (time · who · action · order code); per-cashier totals (handledBy); scheduled incremental export (by updatedAt).
Encode historical sales
An admin tool that records a past sale into the ledger on a chosen business date (a field it keeps out of the per-cashier totals); a config flag can hide it while the encoded rows stay in the ledger.
One RTDB stream
The dashboard reads the one RTDB stream (online + counter orders).
