Kitchen · Flowchart

Kitchen board

Read-only by design: zero input, zero login, zero cook interaction. The server owns lanes, promotion, and expiry — the cook owns nothing.

Spec

Open /kitchen
Reached via a secret URL — no login, kiosk-level access.
Ticket board
Two lanes. NOW and LATER.
NOW
Oldest first. Shows order code and age timer (red at 12 min). Walk-ins enter at settle with their code. NEW tickets flash ~5 s, badge until age 3 min. All-day = NOW only.
LATER
Scheduled pickups, full-size dimmed rows, ready-for + countdown.
Promotion
The server promotes LATER → NOW at pickup − 15 min or at verify (whichever is later); both clocks run, LATE immediately if overdue.
Board poll
Fixed 5 s fetch + heartbeat; stale >15 s shows “Reconnecting…” and auto-reloads. Verified, unserved orders only.
Mark served
Cashier marks an order served → ticket leaves NOW.
Reject proof
Cashier rejects a proof → ticket leaves NOW instantly (the board mirrors verified, unserved orders).
Approve rejected proof
Cashier approves a rejected proof → ticket rejoins NOW by age; timer never restarted.
Ready-for + 15 min
Any NOW ticket at ready-for + 15 min or at close: the server clears it off the board → cashier ready-awaiting-handover row.
Cook rule
The cook never touches the board: no editing, no statuses, no session.
