Customer · Flowchart

Customer — browse to order

Browse is open to everyone; ordering requires Sign in with Google. Online orders are pickup-only, GCash-only, identified by order code. Payment is in customer-payment.html; rentals and the read-only views are in customer-rentals.html.

Spec

Browse
Open to everyone — the menu is visible with no login wall. Filter by tapping a category chip.
Open?
Hours + force-close + scheduled closures + GCash number & QR configured. Closed or setup incomplete → read-only: menu + announcement, place-order disabled with a plain reason (admin sees “Complete setup”). Open → the menu.
Menu
Grouped by category, promo / Top 3 tags, computed prices, served from the catalog cache (no image re-read per view).
Product page
Add to cart with steppers, add-ons, and computed totals.
Per-account prefs
Favorites and the last add-on selection save to users/{uid} and sync across devices; the last pick is pre-checked in the cart.
Cart
Inline steppers + add-on picks; last pick pre-checked from users/{uid}; totals recompute server-side.
Sign in
Sign in with Google — one tap, session remembered.
Checkout
Pickup time, default ASAP; earliest = now + 15 min.
Place order
POST to Laravel: validated, throttled, idempotency key. Returns the order code + GCash number + QR; the 15-minute payment window (deadlineAt) starts.
