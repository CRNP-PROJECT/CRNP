# Ponytail Audit — dead code removal

**Goal:** Delete everything that isn't used, nothing more.

**Findings after tracing every function caller:**

| Function | Lines | Callers | Verdict |
|---|---|---|---|
| `cache_get()` | 4 | 0 | **Delete** — `cache_remember` does the job |
| `restore_product_stock()` | 5 | 0 | **Delete** — `restore_rent_stock` exists for rent, product version never called |
| `lastError()` | 3 | 0 | **Delete** — error already logged via `error_log()` |
| `items_summary($items)` | 6+6 | 2 separate files | **Note** — duplicated with different behavior. Admin variant shows names+qty, user variant only counts. Either consolidate or leave as sibling helpers (both are ~6 lines, no win in extracting) |

**Total: 3 deletions, 12 lines gone. Nothing else to cut — the rest of the codebase is flat PHP files, no framework, no dead routes, no orphaned pages.**

---

## Task 1: Delete `cache_get()`

**File:** `includes/functions.php:279-282`

Remove:
```php
function cache_get(string $key) {
    global $__cache;
    return $__cache[$key] ?? null;
}
```

`cache_remember()` (line 287) reads `$__cache` directly — `cache_get` is a public API that nothing calls.

## Task 2: Delete `restore_product_stock()`

**File:** `includes/functions.php:218-222`

Remove:
```php
function restore_product_stock(firebaseRDB $db, string $productId, int $qty): void {
    $row = $db->retrieve('/products/' . $productId);
    $cur = (is_array($row) && isset($row['stock'])) ? (int)$row['stock'] : 0;
    $db->update('/products', $productId, ['stock' => $cur + $qty]);
}
```

`decrement_product_stock()` is called every order placement. But `restore_product_stock` has zero callers — orders aren't cancelled with stock restore. If cancellation logic ever needs it, add it then.

## Task 3: Delete `lastError()`

**File:** `firebaseRDB.php:98-100`

Remove:
```php
public function lastError(): string {
    return $this->lastError;
}
```

The private `$this->lastError` is still written on line 118, and the error is logged via `error_log()` on line 119 — that's enough for debugging. Nobody calls `lastError()`.

## Not cut (with reasoning)

| Item | Why not |
|---|---|
| `items_summary` duplication | Different behavior (detail vs count). Consolidating would add complexity to save 6 lines. |
| `firebaseRDB::LIKE` constant | Used in exactly one place (cashier/history.php). Single-use constant is fine in PHP. |
